# الرئيسية: واجهة اللوح التفاعلي لغرفة الرياضيات

برنامج صغير يفتح بملء الشاشة عند تشغيل جهاز اللوح، ويبدو مثل شاشة تابلت أندرويد: خلفية هادئة، وساعة بيضاء كبيرة، وأيقونات دائرية تفتح بلمسة واحدة، بدل سطح مكتب ويندوز.

![شكل الواجهة](docs/preview.png)

- **السبورة**: أكبر أيقونة على الشاشة (الدائرة الخضراء)، تفتح برنامج اللوح التفاعلي.
- **باوربوينت، التنزيلات، الإنترنت، تيمز.**
- **الفلاشة والملفات**: تفتح الفلاشة الموصولة، وإن لم توجد فلاشة تفتح ملفات الجهاز. عند إدخال فلاشة تُفتح وحدها ويظهر شريط أصفر في الأسفل.
- **الألعاب والمواقع التعليمية**: كل موقع أيقونة مستقلة تفتح بلمسة (جيوجبرا، ديسموس، ووردوول أمثلة مؤقتة).
- **لوحة المفاتيح**: تُظهر لوحة مفاتيح اللمس (ولو لم تظهر بالطريقة العادية تُفتح لوحة المفاتيح الكلاسيكية).
- **ضبط اللمس**: يفتح أداة المعايرة مباشرة.
- **قائمة المشرفة**: اضغطي على الساعة 3 ثوانٍ، ثم أدخلي الرمز.

**التنقل مثل التابلت:**
- عند إغلاق أي برنامج تظهر الواجهة تلقائياً لأنها تبقى خلف كل البرامج.
- **زر الرئيسية العائم** (دائرة صغيرة فيها بيت، أسفل يسار الشاشة) يظهر فوق أي برنامج مفتوح. لمسة واحدة تعيد الواجهة، والبرنامج يبقى مفتوحاً.
- **«مفتوح الآن»** أسفل الواجهة: بطاقة لكل برنامج مفتوح. لمسة على البطاقة ترجع إليه، و✕ تغلقه.
- شريط مهام ويندوز يُخفى تلقائياً، ويرجع كما كان عند خروج المشرفة إلى سطح المكتب.

## خطوات التثبيت

**تحتاجين:** حساب مدير وكلمة سره، تُدخلينها مرة واحدة فقط. لا يلزم اتصال بالإنترنت.

### ١. تنزيل الملف وفكّه
1. نزّلي ملف `MathBoardHome.zip` من صفحة **Releases** في هذا المستودع.
2. انقري على الملف بالزر الأيمن ← **خصائص** ← ضعي علامة على **إلغاء الحظر (Unblock)** في الأسفل ← **موافق**.
3. انقري عليه بالزر الأيمن مرة أخرى ← **استخراج الكل** ← **استخراج**.

### ٢. تشغيل التثبيت
1. افتحي المجلد المستخرج `MathBoardHome` وانقري مرتين على **`install.bat`**.
2. إن ظهرت رسالة زرقاء «Windows protected your PC»: اضغطي **More info** ثم **Run anyway**.
3. تظهر نافذة صلاحيات ويندوز: أدخلي **اسم المستخدم وكلمة سر المدير**. هذه المرة الوحيدة التي تُطلب فيها.

### ٣. الإجابة عن أسئلة النافذة السوداء
1. **برنامج السبورة**: تظهر قائمة مرقّمة بالبرامج المرشّحة. اكتبي رقم برنامج اللوح واضغطي Enter.
   - إن لم يظهر في القائمة اكتبي `B` واختاري ملف البرنامج (exe) بنفسك.
   - لمعرفة مكانه: انقري بالزر الأيمن على أيقونة برنامج اللوح في سطح المكتب ← **فتح موقع الملف**.
2. **أداة المعايرة**: إن كان للوح أداة معايرة خاصة به فاختاري رقمها. وإلا اضغطي Enter، فيستعمل الزر أداة ويندوز.
3. **رمز المشرفة**: اكتبي رمزاً من 4 إلى 8 أرقام واحفظيه عندك. الرمز المبدئي `2468`، فلا تتركيه.
4. عند ظهور كلمة **Finished** اضغطي أي زر لإغلاق النافذة.

### ٤. التجربة
أعيدي تشغيل الجهاز وادخلي بحساب المعلمات. يجب أن تفتح الواجهة وحدها. جرّبي كل زر:

- [ ] السبورة تفتح برنامج اللوح
- [ ] باوربوينت يفتح
- [ ] إدخال فلاشة يفتح ملفاتها ويُظهر الشريط الأصفر
- [ ] التنزيلات، الإنترنت، تيمز
- [ ] أيقونات المواقع التعليمية تفتح المتصفح على الموقع الصحيح
- [ ] لوحة المفاتيح تظهر
- [ ] ضبط اللمس يفتح المعايرة **بلا طلب كلمة سر**
- [ ] إغلاق أي برنامج يعيدك إلى الواجهة
- [ ] زر البيت العائم يعيد الواجهة والبرنامج ما زال مفتوحاً
- [ ] بطاقات «مفتوح الآن» ترجع إلى البرنامج وتغلقه
- [ ] الضغط على الساعة 3 ثوانٍ يفتح لوحة رمز المشرفة

## للمشرفة

| تريدين أن… | الطريقة |
|---|---|
| تخرجي إلى سطح المكتب | الساعة 3 ثوانٍ ← الرمز ← **الخروج إلى سطح المكتب** |
| تعيدي فتح الواجهة | أيقونة **الرئيسية - غرفة الرياضيات** في سطح المكتب، أو أعيدي التشغيل |
| تغيّري الأزرار أو الروابط | قائمة المشرفة ← **تعديل ملف الإعدادات** (تطلب كلمة سر المدير) ← احفظي ← **إعادة تحميل الإعدادات** |
| تحدّثي البرنامج | ثبّتي الإصدار الجديد بنفس الطريقة. الإعدادات القديمة تبقى كما هي |
| تزيلي البرنامج | `uninstall.bat` من مجلد التثبيت المستخرج |

### ملف الإعدادات `config.json`
موجود في `C:\Program Files\MathBoardHome\config.json`. أهم ما فيه:

- `title`: النص في أسفل الشاشة.
- `adminPin`: رمز المشرفة.
- `hideTaskbar`: إخفاء شريط مهام ويندوز تلقائياً (المبدئي `true`).
- `homeButton` و`homeButtonPosition` و`homeButtonSize`: زر الرئيسية العائم ومكانه (`bottom-left` أو `bottom-right` أو `bottom-center` أو `middle-left` أو `middle-right`) وحجمه.
- `usbAutoOpen`: فتح الفلاشة تلقائياً عند إدخالها.
- `digits`: `"arab"` للأرقام العربية (١٢٣) أو `"latn"` للأرقام (123).
- `wallpaper`: اسم صورة خلفية تضعينها في مجلد `wwwroot` (اتركيها فارغة للخلفية الأصلية).
- `apps`: الأزرار بالترتيب. كل زر له `name` (الاسم) و`icon` و`color`، و`targets` وهي قائمة بالبرامج أو الروابط التي يُجرَّب فتحها بالترتيب حتى ينجح أحدها.

مثال لإضافة موقع تعليمي جديد (ضعيه داخل قائمة `apps`):
```json
{ "id": "kahoot", "name": "كاهوت", "icon": "games", "color": "#46178F", "type": "url", "url": "https://kahoot.it" },
```
أفضل عدد للأيقونات الصغيرة 10 (صفّان من 5). الأكثر يضيف صفاً ثالثاً.
كل `id` يجب أن يكون فريداً. وانتبهي للفاصلة بين العناصر.

### إن لم يعمل شيء
- **الواجهة بيضاء أو فارغة**: ثبّتي «Microsoft Edge WebView2 Runtime» من موقع مايكروسوفت.
- **ويندوز يمنع تشغيل البرنامج** (Smart App Control): البرنامج غير موقّع رقمياً. أوقفي هذه الميزة من أمان Windows ← التحكم في التطبيقات والمتصفح.
- **زر لا يفتح شيئاً**: تظهر رسالة على الشاشة. راجعي مساره في ملف الإعدادات.
- **سجل الأخطاء**: `%LOCALAPPDATA%\MathBoardHome\log.txt` في حساب المعلمات.

## للمطوّرين
- `src/MathBoardHome`: برنامج C# على .NET Framework 4.8 (مدمج في ويندوز 11) يعرض الواجهة عبر WebView2.
- `src/MathBoardHome/wwwroot`: الواجهة (HTML/CSS/JS). الخط Readex Pro (رخصة OFL) والأيقونات من Lucide (رخصة ISC).
- `installer`: سكربتات التثبيت والإزالة.
- كل دفعة إلى `main` تبني الملف وتنشره في Releases عبر GitHub Actions.

البناء محلياً (يعمل على ويندوز ولينكس):
```bash
dotnet build src/MathBoardHome -c Release
```
